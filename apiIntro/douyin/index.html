API 简介

API Overview

解析国内抖音视频分享链接，返回视频标题、封面、播放地址、作者信息及互动数据。仅支持国内抖音，不支持 TikTok。

Parses Douyin (Chinese TikTok) video share links and returns video title, cover, play URL, author info, and interaction stats. Supports Douyin only — TikTok is not supported.

基础地址

Base URL

https://api.furry.ist/douyin

支持的 HTTP 方法

Supported HTTP Methods

支持 GET。

Supports GET.

查询参数

Query Parameters

参数名Parameter 类型Type 必填Required 说明Description
url String 是Yes 抖音视频分享链接，如 https://v.douyin.com/DQyLiuMdIlk/Douyin video share URL, e.g. https://v.douyin.com/DQyLiuMdIlk/

响应字段

Response Fields

字段名Field 类型Type 说明Description
ok Boolean 请求是否成功Whether the request succeeded
data Object 视频数据对象（仅 ok=true 时存在）Video data object (only present when ok=true)
data.aweme_id String 视频唯一 IDUnique video ID
data.desc String 视频标题 / 文案Video description / caption
data.author Object 作者信息，含 nickname（昵称）和 signature（个人简介）Author info including nickname and signature
data.cover String 视频封面图片 URLVideo cover image URL
data.duration_ms Number 视频时长（毫秒）Video duration in milliseconds
data.create_time String 视频发布时间Video publish time
data.source_url String 原始分享链接Original share URL
data.type String 内容类型，video 或 imageContent type: video or image
data.video_url String 视频播放地址（type=video 时有效）Video play URL (valid when type=video)
data.image_url_list Array<String> 图集图片列表（type=image 时有值）Image list for image posts (populated when type=image)
data.statistics Object 互动数据，含点赞、评论、分享、收藏、播放数量Interaction stats including likes, comments, shares, collects, and plays

错误响应

Error Responses

codecode 场景Scenario 返回示例Example Response
MISSING_URL 未传入 url 参数Missing url parameter {"ok":false,"code":"MISSING_URL","message":"Missing query param: url"}
INVALID_URL url 格式无效或非抖音链接Invalid URL or non-Douyin link {"ok":false,"code":"INVALID_URL","message":"Invalid url"}
PARSE_STATS_FAILED 解析响应时未找到统计数据No statistics found in the parsed response {"ok":false,"code":"PARSE_STATS_FAILED","message":"No statistics found in response"}
