Query IP address information using `ipapi`, `ipinfo`, or `bilibili`, and choose the data source via the `?db=` parameter.

一言 API Hitokoto API

随机返回一条句子，来源涵盖动画、漫画、游戏、文学、诗词等多个分类。支持按分类筛选、长度过滤，并可选择 JSON 或纯文本格式返回。
Returns a random sentence from categories including anime, manga, games, literature, and poetry. Supports category filtering, length filtering, and JSON or plain-text output.

抖音内容解析API Douyin Content Parse API

解析国内抖音分享或详情链接，返回视频、图集、实况图、作者、音乐及互动数据。仅支持国内抖音，不支持 TikTok。
Parses Douyin share or detail links and returns video, image, live-photo, author, music, and interaction data. Douyin only — TikTok not supported.
